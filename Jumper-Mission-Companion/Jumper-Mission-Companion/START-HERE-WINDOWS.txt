JUMPER MISSION COMPANION - WINDOWS STARTUP

1. Download the complete ZIP. Right-click it and choose Extract All.
2. Extract into a short folder such as D:\JumperLab.
3. Open the extracted folder that contains Start-Windows.cmd.
4. Double-click Start-Windows.cmd. Do not run it inside the ZIP preview.

The launcher needs 64-bit Python 3.12 or 3.13 already installed.
If Python is missing, it shows the official download address.
Git is not required for a fresh installation.

First launch downloads the official robot assets and Python dependencies.
Keep the command window open; this can take several minutes.
When the local application responds, your browser opens automatically.

If startup fails, the window stays open and saves windows-startup.log
in the same folder. Send the last 15-20 lines of that log for diagnosis.

This is a Python application, not a standalone Windows EXE.
The ZIP has been checked for corruption. Windows-specific startup fixes
were added, but this package has not been executed on a Windows machine here.

Nothing is published or uploaded by this launcher.
